# arch-code-check

Architectural design-code quick lookup and drawing self-check.

## What it is

A skill for landscape-architecture / architecture coursework. Before and after
drawing plans, elevations, sections and site plans, it walks through hard
requirements: clear heights, areas, evacuation, accessibility, line types and
sheet sizes.

## Contents

- `references/01-code-quick-reference.md` — commonly used numeric requirements
- `references/02-drawing-checklist.md` — self-check list for drawing sets
- `references/03-code-sources.md` — where the original code documents live

## Usage

Load this skill when the task involves architectural design standards,
clear height, floor height, evacuation, accessibility, drafting standards or a
final drawing review.

## Notes

The references were written for Chinese national standards (GB). Adjust the
numbers if you work under a different code.
