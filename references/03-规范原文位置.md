## 怎么用

**能提取文字的**（有"文字层"的）：直接用文本搜索定位条款，再用页码回查。

**扫描件**（无文字层）：只能：
1. 用 `pymupdf` 渲染成图片 → 看图（vision 能力）
2. 或者找带 OCR 的另一版本

## 提取方法（可复用）

```python
import pymupdf
d = pymupdf.open(r"...\饮食建筑设计标准JGJ_64-2017.pdf")
for i in range(d.page_count):
    t = d[i].get_text()
    if "净高" in t:
        print(i + 1, t[:400])
```
