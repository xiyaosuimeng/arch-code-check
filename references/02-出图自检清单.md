# 02 · 出图自检清单

> 交图前逐条打勾。**每条必须能指到图纸上的具体位置**；指不出来的写"未验证"，不许打勾。
> 依据：《风景园林建筑设计Ⅰ》任务书 + 上面的规范速查。

---

## A. 场地设计

- [ ] 现状分析图（用地、周边道路、湖面、绿道、3 株乔木）
- [ ] 总平面图 **1:500**
  - [ ] 场地道路与外部道路的衔接关系
  - [ ] 道路红线 / 建筑红线（本作业标注**建筑用地红线**）
  - [ ] 建筑顶视图、台阶、广场、绿化
  - [ ] 行车通道、**回车场**
  - [ ] 室外就餐区 + 配套设施（若有）
  - [ ] 场地竖向标高、建筑室外地坪标高
  - [ ] 坡道/台阶的高度及坡度
  - [ ] 建筑与周边道路、场地的距离尺寸
  - [ ] 建筑出入口位置
- [ ] 场地分析图：功能分区 / 交通流线（公共、内部、货物三条）
  - [ ] 图例清晰
  - [ ] 文字说明，逻辑贴合设计主题

## B. 建筑平面 **1:200**

- [ ] 各层平面**直接注明房间名称及建筑面积**
- [ ] **首层三道尺寸线**（总尺寸 / 轴线尺寸 / 细部尺寸）
- [ ] 柱网轴线编号及尺寸
- [ ] 墙体厚度标注
- [ ] 门窗洞口尺寸
- [ ] 餐饮部分：柜台与桌椅布置方式、**座位数量及区域**
  - [ ] 散座 / 火车座 / 酒吧座 分别标数量
  - [ ] 合计核对任务书 60–80 座
- [ ] 厨房：**功能分区 + 设备摆放位置**（洗消区虚线框 6㎡、炉具、烤箱、冷藏柜…）
- [ ] 其他房间室内大致布置（办公室桌椅等）
- [ ] 所有出入口分类标注：**公共入口 / 内部入口 / 货物入口**
- [ ] 无障碍设施位置（坡道、无障碍厕位）
- [ ] 消防疏散通道及安全出口
- [ ] 楼梯间位置
- [ ] 剖切符号（1-1、2-2，位置要剖到楼梯与出入口）

## C. 立面 **≥2 个，1:200**

- [ ] 选主要立面（临景区主路 / 建筑主入口）
- [ ] 材质、色彩标注
- [ ] 门窗形式及尺寸
- [ ] 建筑总高度
- [ ] 各层标高
- [ ] 局部造型高度
- [ ] 结合地域特色的造型处理

## D. 剖面 **2 个，1:200**

- [ ] 剖到**楼梯**、空间高度变化位置、主要出入口
- [ ] 各层净高
- [ ] 各层层高
- [ ] 建筑总高度
- [ ] 室外地坪标高、各层楼地面标高
- [ ] **梁、板、柱位置及大致尺寸**
- [ ] 地形高差与建筑的结合
- [ ] 坡道、台阶坡度及高度
- [ ] 不同空间净高要求（对照 JGJ 64：用餐 2.6 / 厨房 2.5）

## E. 分析图

- [ ] 场地现状分析
- [ ] 功能分区分析
- [ ] 交通流线分析（公共 / 内部 / 货物，三色区分）
- [ ] 图例 + 文字说明

## F. 表现图

- [ ] 建筑透视图 ≥1 张
- [ ] 建筑鸟瞰图 1 张
- [ ] 表达造型、场地关系、空间氛围、材质

## G. 图纸整体

- [ ] 画在 **2–3 张 A2（420×594）** 上
- [ ] 排版整洁、图例统一、标注清晰、符合制图规范
- [ ] 右下角**全班统一图签**：姓名 / 指导教师 / 日期 / 图纸名称 / 比例
- [ ] **设计说明**：设计构思、功能布局、造型设计、地域适配、无障碍设计、消防设计
- [ ] **主要经济技术指标**：总用地面积、总建筑面积、各功能分区面积、建筑密度、容积率、绿地率、停车位数量
- [ ] 每张图下方有**图名 + 比例**

## 规范符合性自检（画完后跑一遍）

| 检查项 | 要求 | 实测 | 结论 |
|---|---|---|---|
| 用餐区净高 | ≥ 2.6m（无集中空调） | | |
| 厨房加工间净高 | ≥ 2.5m | | |
| 楼梯梯段净高 | ≥ 2.26m | | |
| 楼梯平台净高 | ≥ 2.00m | | |
| 踏步级数 | 2–18 级/梯段 | | |
| 用餐区座位面积 | ≥ 1.5 ㎡/座（饮品店） | | |
| 用餐区采光 | 窗洞口 ≥ 地面 1/6 | | |
| 加工间通风 | 开口 ≥ 地面 1/10 | | |
| 无障碍设计 | 必须有（JGJ 64 §4.1.11） | | |
| 公共卫生间门 | 不直接开向用餐区 | | |
| 图线线宽 | 粗/中粗/细 成组 | | |
| 比例注写 | 图名右侧、字高小一号 | | |
| 字高 | ≥ 2.5mm | | |
